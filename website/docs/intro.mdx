## Why discipline needs to be code

A platform's standards are only as strong as the place they live. When they live in a
wiki, they drift the moment someone is in a hurry. When they live in CI `if:` expressions
and review vigilance, nobody can say what a change will do without running it. And a
coding agent joining the team inherits all of that fog at machine speed: it copies the
nearest example, not the standard.

orun moves the standards into the repository, in a language that both people and tools
can read:

## The loop

```text
   DECLARE                      PACKAGE & EVOLVE                 GROUND AGENTS
   intent.yaml                  Stacks (golden paths, OCI)       orun mcp · orun skills
   component.yaml        ◀──    intent presets (extends:)   ──▶  base literacy · agent types
   compositions                 baselines (whole products)       task contracts (affects)
        │                                                              │
        │                 agents propose changes to intent  ◀──────────┘
        ▼
   VERIFY ─────────▶ PLAN ─────────────▶ EXECUTE ───────────▶ RECORD
   orun validate     orun plan           orun run              .orun/ object graph
   intent, rules     schemas, plan.json  shell · docker · gha   catalog · status · logs · tui
```

Standards are declared once, packaged so they can travel, and read by every agent that
works in the repository. The runner is the checkpoint: nothing executes that was not first
verified and compiled into a plan you can review.

## Orunbase, when a team shares it

`orun` is local-first: it is a single binary, and its state lives in your repository's
`.orun/`. **[Orunbase](https://docs.orunbase.com)** is the hosted control plane you add when
a team shares that state: workspaces, managed remote state, live runs, a console, the task
plane, sandboxed agents, and the registry of baselines you can build whole products from.
Sign in with [`orun auth login`](/cli/orun-auth) and pick a workspace with
[`orun workspace use`](/cli/orun-workspace). Orunbase is itself open source and written as
orun intent.
