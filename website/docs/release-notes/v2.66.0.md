Released 2026-09-29. The third CLI half of the Orunbase work-as-code epic
(orun-cloud `saas-work-gitops`): the declaration in the repository becomes
the epic in Orunbase, without anyone minting anything by hand.

Binaries and the merged-pull-request list are on the
[GitHub releases page](https://github.com/sourceplane/orun/releases).

## `orun work sync`

Creates the epic by slug, sets its declared fields and state (forward
only), creates and orders the milestones, creates each listed task with the
key the tree chose and its contract attached, pushes every doc — and never
deletes: a milestone or task the tree no longer names is reported and left.
Every write is idempotent by repo, path and commit and carries
`X-Orun-Work-Sync`, which the platform stamps as the epic's `managedBy`
pointer. `--dry-run` prints the plan. See [`orun work`](../cli/orun-work.md#sync).
