# Changelog

orun follows [semantic versioning](https://semver.org). Every release is
published on the [GitHub releases page](https://github.com/sourceplane/orun/releases)
with binaries, checksums, and the list of merged pull requests.

Narrative release notes, which explain what changed and why, live on the
documentation site under
[Release notes](https://orun-docs.pages.dev/release-notes/v2.58.0). The most
recent are:

| Version | Date | Highlights |
|---|---|---|
| [v2.58](https://orun-docs.pages.dev/release-notes/v2.58.0) | 2026-09-16 to 2026-09-19 | `orun baseline new --via-platform`, `orun baseline register` and `publish`, the bootstrap driver, and the build-hardening patches through v2.58.15 |
| [v2.57.0](https://orun-docs.pages.dev/release-notes/v2.58.0#v2570) | 2026-09-15 | `orun baseline new --local` |
| [v2.56.0](https://orun-docs.pages.dev/release-notes/v2.58.0#v2560) | 2026-09-15 | `orun baseline` (the registry from the command line), typed hook actions, phase preconditions and waits, derived phase state |
| [v2.55.0](https://orun-docs.pages.dev/release-notes/v2.58.0#v2550) | 2026-09-11 | `orun task` epics and milestones, `orun spec`, the task plane on the MCP, `orun pr open` with a body file |
| [v2.54.0](https://orun-docs.pages.dev/release-notes/v2.54.0) | 2026-08-16 | The work plane removed; `orun pr`, the provenance pen |
| [v2.52.0](https://orun-docs.pages.dev/release-notes/v2.52.0) | 2026-08-03 | The task plane and the object-model contract |

For anything older, see the release notes index on the documentation site or
the GitHub releases page.
