**platform discipline as code** (milestone PD6, the reference sweep). The
binary is unchanged from v2.73.4.

## Reference sweep

- Every page in the docs now has a description.
- Stale version pins are gone: the installation page and README use v2.73.4,
  the `orun work` CI example uses `orun-action@v1` like the other guides, and
  workflow pages say "since v2.35.0" instead of naming an internal project.
- The CLI reference matches the binary: `orun catalog diff [component]` with
  `--base` and `--head`, `describe execution` as an alias of `describe run`,
  and one description of the legacy `--config-dir` fallback.
- The [glossary](../overview/glossary.md) defines Stack, intent preset,
  source pin, and composition lock as the code has them.
- The architecture map lists `internal/inputglob` and `internal/workfile`.
- `orun backend` no longer names a stale default URL for Orunbase.
