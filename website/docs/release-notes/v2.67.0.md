## `orun pr check --standards` is removed

The standards mode layer added in [v2.63.0](./v2.63.0.md) and extended in
[v2.65.0](./v2.65.0.md) is gone:

- `orun pr check --standards` is removed. Passing `--standards` is now an
  unknown-flag error; drop it from any CI step that runs `pr check`.
- The `ORUN_STANDARDS` environment variable is no longer read.
- `execution.standards` in `intent.yaml` is removed. An intent that still
  declares it loads unchanged — the key is ignored — so delete the line at
  your convenience.

`orun pr check` is again the provenance preflight only: the branch
grammar, the `Orun-Task` trailer on every commit ahead of the base, a
well-formed manifest naming the same task, one task per PR — the rules the
cloud's `orun/compliance` check verifies, with the same output and exit
codes as before v2.63.0. See [`orun pr`](../cli/orun-pr.md#check).

`orun work check` and `orun work sync` are unchanged; `work check` is the
command that validates the declared work tree. See
[`orun work`](../cli/orun-work.md).
