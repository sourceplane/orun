## `orun work sync` respects where a workspace creates work

A workspace can choose one channel that creates its new epics: the
repository, its tracker, or the console (Settings → Work). When the
setting names a channel other than the repository, the platform refuses
a new epic from the sync with `412 precondition_failed`, reason
`authored_elsewhere`. The sync now warns and moves on to the next epic:

```text
warn           epic q4-launch — not created — this workspace creates new work in its tracker (Settings → Work); skipped
synced 3 epic(s) at 0123456: 4 write(s), 1 warning(s)
```

Before this release that refusal failed the run, and with it the job on
main. Epics that already exist keep syncing, whatever the setting says.

## Reconcile and doctor can name a connection

When an account holds more than one connection to the same provider,
reconcile and doctor take the connection to use (#708).
